## 📋 О проекте

Единая веб-платформа, объединяющая четыре инструмента для работы с данными:

| Модуль | Описание |
|--------|----------|
| 🚀 **Jenkins** | Управление сборками и загрузкой данных в БД |
| 📊 **Excel Парсер** | Парсинг выгрузок из 1С с накоплением данных |
| 📈 **Прогнозирование** | Анализ и прогноз продаж с помощью ML моделей |
| 📑 **Ежемесячный отчет** | Автоматическое формирование Excel отчетов |

## 🚀 Быстрый старт

### Требования
- Python 3.12+
- PostgreSQL (для модулей Прогнозирования и Ежемесячного отчета)
- Jenkins (для модуля управления сборками)

### Установка

#### 1. Клонирование репозитория
```bash
git clone https://github.com/denisalkulikov/kamtent_report_union.git
```

```bash
cd kamtent_report_union
```

#### 2. Установка UV (если не установлен)
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
или для Windows:
```bash
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

#### 3. Установка зависимостей
```bash
uv sync
```

#### 4. Настройка переменных окружения

#### 5. Запуск приложения
```bash
uv run python main.py
```
>Приложение будет доступно по адресу: http://localhost:8001

## 📦 Модули

### 1. 🚀 Jenkins Control
Управление CI/CD pipeline для загрузки данных в базу данных.

*Возможности:*
- Запуск сборки из веб-интерфейса
- Просмотр логов в реальном времени
- Отслеживание прогресса выполнения
- Прямая ссылка на консоль сборки

*Использование:*
- Нажмите ▶️ Запустить сборку
- Следите за логами в окне приложения
- При необходимости подтвердите действия в Jenkins

> ⚠️ **Важно:** Pipeline содержит этапы с подтверждением загрузки в БД. Откройте Jenkins в браузере для подтверждения.

### 2. 📊 Excel Парсер
Парсинг Excel-файлов (выгрузок из 1С) с накоплением данных и экспортом в CSV.

*Возможности:*
- Поддержка .xls и .xlsx
- Накопительный режим (несколько файлов)
- Автоопределение структуры (объединенные ячейки)
- Экспорт в CSV с русской кодировкой

*Использование:*
- Загрузите Excel-файл через drag-and-drop или по клику 
- Данные автоматически накопятся в таблице
- Нажмите 📥 Экспорт всех данных в CSV для выгрузки

### 3. 📈 Прогнозирование
Анализ исторических данных и построение прогнозов продаж.

*Возможности:*
- Три уровня агрегации: месяцы, недели, дни
- Модели: Prophet, Holt-Winters, SARIMA
- Разбивка по направлениям (ОАИ, ТК, КН, РЕКЛАМА, АНГАРЫ)
- Детализация по товарным группам

*Использование:*
- Нажмите Загрузить данные
- Выберите год для прогноза
- Выберите уровень агрегации
- Нажмите Сделать прогноз

### 4. 📑 Ежемесячный отчет
Автоматическое формирование Excel-отчетов на основе данных из PostgreSQL.

*Возможности:*
- Выбор года и месяца
- Заполнение Excel-шаблона данными из БД
- Копирование данных из файла-источника прошлого периода 
- Автоматическое скачивание готового отчета

*Использование:*
- Выберите год и месяц
- Введите сумму реализации
- Нажмите Получить данные
- Загрузите файл-шаблон (.xlsm)
- (Опционально) Загрузите файл-источник
- Нажмите Создать отчет

## 🐛 Устранение неполадок

### Ошибка подключения к БД
```bash
# Проверьте настройки в .env файле
# Убедитесь, что PostgreSQL запущен
sudo systemctl status postgresql  # Linux
```

### Ошибка 403 Jenkins
Используйте API Token вместо пароля

>Jenkins → Ваш профиль → Configure → API Token

Убедитесь, что у пользователя есть права на запуск задачи

### Проблемы с прогнозированием
```bash
# Установите Prophet отдельно (требует компилятора)
uv add prophet
```

```bash
# Или через pip:
pip install prophet
```

### Медленная загрузка страницы
```bash
# Отключите автообновление в main.py
ui.run(reload=False)
```
